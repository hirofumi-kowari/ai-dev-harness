# ハーネスによるAI駆動開発

[English](README.md)

**AIが設計からテストまで自動で進め、人が必要な判断と承認を行う。** その開発の流れと、それを支える仕組み「ハーネス」を2本の動画で紹介します。

ハーネスとは、参照資料・作業手順・ツール・確認の仕組みを組み合わせ、AIが作業・検証・修正を続けられるようにするものです。

題材は架空の社員予約管理システムで、画面やコードは説明用のものです。ナレーションは日本語（合成音声）です。英語版の動画は [English](README.md) のページで紹介しています。

## 1. まず見る：AI駆動開発デモ動画（約8分）

予約の上限を週5件にし、残り件数を表示する改修を例に、設計書の更新から実装・テストまでを追います。AIが不明点を人に確認し、テストで問題が見つかれば原因を調べて修正・再テストを進めます。人は変更内容・検証結果・残る課題を確認して承認します。最後に、今回の経験を次の開発に向けた手順の改善につなげます。

## 2. 仕組みを知る：ハーネス技術編（約8分）

デモを支えるハーネスの作り方を説明します。参照資料の整理、基本指示や作業手順（Skills）の用意、ツールの実行、レビューや自動チェックの組み込み方を紹介します。工程ごとのチェックリストや報告前の確認（品質ゲート）を通じて、AIが次へ進む条件と、人に確認する条件をどう整えるかを扱います。
